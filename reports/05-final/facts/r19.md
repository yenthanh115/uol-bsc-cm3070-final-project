# R19 — Main predictive model exists

**Requirement:** At least one stronger model (currently Random Forest) is trained successfully and produces probabilities/classes for unseen observations.
**Priority:** MUST
**Assessed:** 2026-09-05
**Verdict:** **PASS**

R19 asks for at least one stronger-than-baseline model that (a) trains successfully and (b)
produces probabilities/classes for unseen (held-out) observations. The project implements *two*
such models — Random Forest and XGBoost — and there is direct artefact evidence that both trained
and emitted probabilities and class predictions on the chronological held-out test set.

---

## 1. A stronger model is implemented (Random Forest + XGBoost)

`src/surge_pipeline/training.py` defines factory functions and grids for the non-linear models
beyond the LR baseline:

- `_make_rf()` → `RandomForestClassifier` (bagged tree ensemble, `class_weight="balanced"`),
  grid `_get_rf_param_grid()` (36 configs).
- `_make_xgb()` → `XGBClassifier` (gradient-boosted trees, `scale_pos_weight` for imbalance),
  grid `_get_xgb_param_grid()` (≤50 configs).

`train_models()` trains all three families (`logistic_regression`, `random_forest`, `xgboost`)
via expanding-window CV + grid search and serialises each. Report `@tbl:model-families` /
`@sec:model-selection` designate RF and XGBoost as the "improved models" against the LR baseline.
(The requirement names Random Forest specifically; the project satisfies it and adds XGBoost.)

## 2. It trains successfully — serialised model artefacts exist

`output/models/` contains trained, serialised models including:
`random_forest_phase2_42.joblib` and `xgboost_phase2_42.joblib` (plus per-experiment
subdirectories A1, A2, B1, B3, C1, C2, G2, G4, G5 and seed variants F2_seed123/456/789/2024).
Each `.joblib` bundle stores the fitted `model`, its `scaler`, `best_params`, and the
`optimal_threshold` (`train_models()` serialisation block), confirming training completed and the
fitted estimator was persisted.

## 3. It produces probabilities and classes for unseen observations

The prediction path emits both a probability and a class for the held-out test partition:

- `training.predict()` / `run_training.py` §4:
  `y_pred = model.predict(X_scaled)` (classes) and
  `y_prob = model.predict_proba(X_scaled)[:, 1]` (probabilities), computed on
  `partition == "test"` (the chronological holdout, isolated from training and threshold
  selection).
- `predict_with_threshold()` additionally derives classes at the validation-tuned threshold.

**Artefact proof.** A frozen evaluation summary
(`output/evaluation/2026-07-19_09-46_final_summary.json`) records, for the 68,923-record WSB test
set (`n_test_samples: 68923`):

| Model | AUC-ROC (from predict_proba) | Confusion matrix (from predict) | Tier |
|-------|------------------------------|----------------------------------|------|
| random_forest | 0.854 | [[59481, 6860], [1073, 1509]] | stretch |
| xgboost | 0.862 | [[50568, 15773], [480, 2102]] | stretch |
| logistic_regression (baseline) | 0.748 | [[46596, 19745], [834, 1748]] | target |

Both stronger models yield a valid AUC (requires probability scores across the unseen set) and a
full 2×2 confusion matrix (requires class predictions across the unseen set) — i.e. they
demonstrably produce *both* probabilities and classes for unseen observations. Both also
`beats_random: true` and clear `achieves_stretch: true`, and improve on the best single feature
(RF +0.091, XGB +0.099 AUC), confirming they are genuinely "stronger" than the trivial and
univariate baselines.

The report's headline results corroborate the same artefacts: on WSB, XGBoost AUC 0.892 and RF
0.880 at the primary threshold (`@tbl:perf-default`); RF leads on the sparse pennystocks community
(0.753). (The specific summary read here is a $\tau=1.0$ configuration, hence 0.854/0.862; the
mechanism — RF/XGB producing test-set probabilities and classes — is identical.)

## 4. Fair, unseen evaluation

Predictions are generated only on the held-out `test` partition, which R12 confirmed is strictly
later than training and untouched by threshold selection. So the probabilities/classes are for
genuinely unseen observations, as R19 intends.

## Verdict

**R19: PASS.** Random Forest (the named main model) and XGBoost are implemented as the
stronger-than-baseline models, train successfully (serialised `.joblib` artefacts exist), and
produce both probabilities (`predict_proba`, yielding AUC-ROC) and class predictions (`predict`,
yielding confusion matrices) on the chronological held-out test set. A frozen evaluation summary
records RF AUC 0.854 and XGB AUC 0.862 on 68,923 unseen WSB records, both clearing the stretch
tier and beating the best single feature. Report and code/artefacts agree.

### Minor observations (not blocking)

- The project exceeds R19 by providing two stronger models and analysing when each wins
  (complexity-vs-data-density, `@sec:complexity-density`).
- The read summary is a $\tau=1.0$ run (RF 0.854 / XGB 0.862); the report's primary results use
  $\tau=1.5$ (RF 0.880 / XGB 0.892). Both are valid runs of the same pipeline; exact-figure
  report/artefact agreement is an R38/R39 concern, not R19.
