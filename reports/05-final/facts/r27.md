# R27 — Results answer the project question

**Requirement:** Evaluation establishes what evidence exists for/against predicting future surge emergence from early social-media signals.
**Priority:** CRITICAL
**Assessed:** 2026-09-05
**Verdict:** **PASS**

R27 asks whether the evaluation delivers an *evidence-based* answer — for and against — to
the project's research question, rather than asserting a verdict. The research question is
stated explicitly in the report ([@sec:problem-motivation]): *"can a social-media surge be
predicted before it happens from early discussion patterns alone?"* The evaluation answers
it in both directions, and every headline figure the answer rests on is produced by code in
`/src` and persisted to artefacts under `output/`, so the answer is grounded, not asserted.

---

## 1. The question is posed and then explicitly answered

- Posed: [@sec:problem-motivation] ("can a social-media surge be predicted before it
  happens from early discussion patterns alone?") and reframed as O1–O3 ([@tbl:objectives]).
- Answered head-on: the Conclusion states "the short answer to the central research
  question is yes: surges can be predicted from backward-looking signals alone," then
  immediately qualifies "how well depends almost entirely on how much data the community
  generates." The answer is conditional and evidence-bound, not a bare claim.
- [@tbl:objective-verdicts] gives a per-objective verdict (all three Met) each pointing to
  the supporting evidence, and [@sec:eval-objectives] ties the verdicts to the results.

## 2. Evidence FOR predictability (grounded in code output)

- **Discrimination well above chance and above the success bar.** `@tbl:perf-default`:
  XGB 0.892 [0.881–0.902] and RF 0.880 [0.869–0.890] on WSB (stretch tier), RF 0.753
  [0.673–0.824] on pennystocks (target), each with 95% bootstrap CIs whose lower bound
  exceeds 0.5.
  - Code: `evaluate_trained_model()`/`evaluate_model()` compute holdout AUC-ROC on the
    `test` partition; `validate_success_tiers()` classifies AUC into
    minimum/target/stretch against 0.60/0.70/0.80.
  - Artefact: `output/evaluation/*_final_summary.json` carries `best_auc_roc`,
    `overall_pass`, `success_tier_achieved`, and per-model `auc_roc`.
- **Beats trivial and single-feature baselines.** `@tbl:baselines`: +0.087 AUC over the
  best single feature on WSB, +0.162 on pennystocks; all models beat random (0.50).
  - Code: `evaluate_baselines()` trains a per-feature single-feature LR and records
    `beats_random`, `best_single_feature`, and `improvement_over_best_single_feature`.
  - Artefact: `baseline_comparisons` block in `*_final_summary.json` (e.g. the 2026-07-08
    summary lists all nine single-feature AUCs and the improvement deltas).
- **Differences are statistically real.** `@tbl:mcnemar`: all pairwise model comparisons
  significant at Bonferroni-adjusted α.
  - Code: `mcnemar_pairwise_test()`; Artefact: `mcnemar_results` in `*_final_summary.json`.
- **Signal is more than one artefact.** Phase 1 vs Phase 2 (`@tbl:phase-comparison`) and
  the weight sweep (`@tbl:weight-sensitivity`) show the composite target adds genuine
  predictive structure (+0.182 AUC on WSB), and feature importance (`@tbl:feature-importance`)
  identifies which signals carry the answer.

## 3. Evidence AGAINST / bounding the answer (equally explicit)

R27 specifically requires evidence *for and against*. The report does not overclaim:

- **Operational usefulness is limited.** `@tbl:acceptance-eval`: at the best operating
  point the system meets AUC (0.892) and precision (0.217) but **fails recall** (0.235 vs
  ≥ 0.50 target) and only partially meets alert volume. [@sec:operational-precision]
  concludes no single threshold satisfies all criteria at 102:1 imbalance.
- **Near-zero precision at the default threshold** across all models (`@tbl:perf-default`),
  framed as a calibration limit.
- **Sparse-community uncertainty**: 31 test surges on pennystocks give wide, overlapping
  CIs (Limitations; [@sec:complexity-density]).
- **Generalisation is conditional**: cross-dataset transfer is asymmetric and needs
  recalibration (`@tbl:transfer`, [@sec:cross-community]); temporal distribution shift
  collapses F1 while AUC holds ([@sec:temporal-stability]).
- **Scope honesty**: the Abstract and [@sec:operational-precision] state the result is
  "insufficient for broad surveillance or moderation coverage and does not justify
  autonomous action."

## 4. The answer is grounded in reproducible code output, not asserted

Every evidential pillar maps to a function and a persisted artefact:

| Evidence for the answer | Code (`src/`) | Artefact |
|-------------------------|---------------|----------|
| Holdout AUC / precision / recall / F1 | `evaluation.evaluate_trained_model` | `*_evaluation_metrics.json`, `*_final_summary.json` |
| Success-tier verdict vs the question's bar | `evaluation.validate_success_tiers` | `tier_results` / `success_tier_achieved` |
| Beats random + best single feature | `evaluation.evaluate_baselines` | `baseline_comparisons` |
| Significance of model differences | `evaluation.mcnemar_pairwise_test` | `mcnemar_results` |
| Uncertainty (95% CIs) | `evaluation.compute_bootstrap_ci` | CI fields / `@tbl:perf-default` |
| Generalisation across communities | `run_cross_validation.evaluate_cross_dataset` | transfer AUCs / `@tbl:transfer` |

The 2026-07-08 `final_summary.json` was inspected directly and contains
`overall_pass`, `success_tier_achieved`, per-model metrics, McNemar results, and baseline
comparisons — confirming the "for/against" evidence is machine-produced.

---

## Verdict

**R27: PASS.** The evaluation establishes, with quantified evidence on a leakage-free
chronological holdout, both what supports predicting future surge emergence from early
social-media signals (stretch/target-tier AUC with bootstrap CIs, significant gains over
random and single-feature baselines, a composite-target contribution) and what argues
against overclaiming it (recall below the operational target, precision-ceiling under
sub-1% prevalence, sparse-community uncertainty, conditional cross-community transfer, and
distribution-shift instability). The report answers the research question directly ("yes,
but bounded by data density and imbalance"), and each figure the answer relies on is
produced by `evaluation.py` / `run_cross_validation.py` and persisted to
`output/evaluation/*`, so the conclusion is grounded rather than asserted.

### Minor observations (not blocking)

- One evidential aside cites "PR-AUC of approximately 0.14" ([@sec:operational-precision]),
  but PR-AUC is not computed in code (raised under R23/R39). R27 does not depend on this
  figure — the for/against case stands on AUC-ROC, precision/recall/F1, baselines,
  significance, and transfer — so it does not affect this verdict.
- The specific headline AUCs (0.892 / 0.880 / 0.753) are the report's frozen final-run
  numbers; exact numeric agreement between report and the latest artefacts is an R38/R39
  concern, not R27, which concerns whether the evaluation *answers the question*.
