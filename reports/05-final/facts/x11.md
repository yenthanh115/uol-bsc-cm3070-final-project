# X11 — Results depend heavily on one random seed/split

**Severity:** CRITICAL
**Failure mode:** Main conclusion may be an accident of a single seed or a single train/test split.
**Final validation:** Re-run with appropriate seeds/windows or otherwise demonstrate stability.
**Assessed:** 2026-09-05
**Status:** **PASS**

The project demonstrates stability against both sources of X11 risk — the random **seed** and the
data **split/window** — through a five-seed robustness sweep, verified run-to-run determinism,
expanding-window cross-validation, threshold and sentiment-weight sweeps, cross-dataset transfer,
and 1,000-sample bootstrap confidence intervals. The single genuinely fragile point (the sparse
`r/pennystocks` sample and the fixed chronological split) is not hidden — it is measured and
disclosed as a limitation. The main conclusion is therefore not an artefact of one seed or one
split.

---

## Evidence 1 — Multiple seeds (the seed axis)

The pipeline was re-run on the `r/pennystocks` baseline (τ=1.5, w₁=w₂=0.5) across **five seeds**.
From `output/experiment_log.jsonl`:

| Seed | Run id | Best model | Best AUC-ROC |
|------|--------|------------|--------------|
| 42   | 2026-07-19_13-14 (A1) | random_forest | 0.752674925737902 |
| 123  | 2026-07-19_13-21 (F2) | xgboost       | 0.7337343652205014 |
| 456  | 2026-07-19_13-24 (F2) | xgboost       | 0.7337343652205014 |
| 789  | 2026-07-19_13-26 (F2) | random_forest | 0.7425216328720308 |
| 2024 | 2026-07-19_13-28 (F2) | random_forest | 0.746152776259972 |

- **Spread:** min 0.7337, max 0.7527, **range 0.0189**, mean 0.7418, std ≈ 0.007 (pop) / 0.008
  (sample).
- Matches the report's Implementation-Status claim: *"robust to seed choice across five seeds
  (42, 123, 456, 789, 2024) … AUC spanning 0.734 to 0.753 (a 0.019 margin)"*.
- The seeds were executed via `scripts/m2.sh` (experiment F2) exactly as laid out in
  `admin/experiment-plan.md`, so the sweep is scripted and reproducible, not ad-hoc.

A 0.019 AUC band across five seeds is small relative to the between-dataset gap
(0.753 vs 0.892 ≈ 0.14) and the model-vs-baseline gap, so the conclusion "surges are predictable,
constrained by data density" does not flip with the seed.

## Evidence 2 — Run-to-run determinism (seed is fully controlled)

The same config + seed reproduces the **identical** metric, confirming there is no uncontrolled
randomness masquerading as seed stability:

- seed 42 baseline → AUC **0.752674925737902** on run `2026-07-19_13-14`, and the **same** value on
  a fresh re-label + re-train `2026-09-05_10-31` (15-dp identical).
- `PipelineConfig` seeds Python `random`, NumPy and every estimator (`random_state`); the
  `TestDeterminism` integration test asserts two runs give identical output (see R20).

## Evidence 3 — Multiple splits / windows (the split axis)

Stability is not argued from seeds alone; several orthogonal perturbations are run:

- **Expanding-window temporal CV** (k=4 → 3 chronological validation splits): the model is evaluated
  over several successive train/validation cut-points, not one split (`@sec:temporal-validation`).
- **Threshold sweep** τ ∈ {0.5, 1.0, 1.5, 2.0, 2.5} and **sentiment-weight sweep**
  w₂ ∈ {0.0, 0.25, 0.5, 0.75, 1.0} (`@tbl:weight-sensitivity`) stress-test the label/threshold
  choices.
- **Cross-dataset transfer** (`@tbl:transfer`) evaluates each model on a *different* community's
  held-out set — the strongest generalisation stress.
- **1,000-sample bootstrap CIs** on the test set quantify metric uncertainty
  (e.g. WSB XGB AUC 0.892 [0.881–0.902]; pennystocks RF 0.753 [0.673–0.824]).

## Evidence 4 — The fragile point is disclosed, not hidden

The report explicitly bounds where stability is weakest, which is exactly what X11 asks for:

- Limitations: *"fixed temporal split (~June 2021) makes test difficulty regime-dependent; training
  variance only partially characterised (0.019 AUC range across 5 seeds)."*
- §Temporal Stability separates **stable ranking** (test AUC 0.880 holds) from **unstable threshold
  calibration** (val F1 0.911 vs test F1 0.210), attributing the gap to distribution shift rather
  than to seed/overfitting.
- The 31-positive `r/pennystocks` test set is flagged as giving wide CIs, so pennystocks-only
  conclusions are called "tentative".

## Scope notes (do not block PASS)

1. **Multi-seed sweep is on `r/pennystocks` only**, not WSB. This is defensible: the sparse
   community is the high-variance stress case, and WSB's tight bootstrap CIs
   (AUC 0.892 [0.881–0.902]) already indicate low sampling variance. The report characterises WSB
   stability via bootstrap CIs and expanding-window CV rather than a seed sweep.
2. **Single fixed train/test split** (chronological 80/20). A single split is *required* here to
   preserve temporal order (random re-splitting would leak). Split-sensitivity is instead probed by
   the expanding-window folds and cross-dataset transfer. The regime-dependence of the fixed split
   is disclosed as a limitation.
3. The report's phrase "identical AUC (0.753)" for seed 42 across two July dates is exact only to
   3 dp (0.7539 vs 0.7527) because those ran on *different* dataset builds; true byte-identical
   determinism is the same-artefact reproduction (Evidence 2). This is an R38 wording nuance, not an
   X11 stability problem.

## Verdict

**X11: PASS.** The main conclusion is demonstrated to be stable rather than a one-seed/one-split
accident: a scripted five-seed sweep bounds seed variance to a 0.019 AUC band, run-to-run
determinism is confirmed, and multiple windows (expanding-window CV, threshold/weight sweeps,
cross-dataset transfer) plus bootstrap CIs probe split/label sensitivity. The residual fragility
(sparse pennystocks sample, fixed chronological split) is measured and explicitly disclosed rather
than concealed. Recommended (non-blocking) strengthening: add a small multi-seed check on WSB and,
for full rigour, a second chronological split point, to convert "partially characterised" training
variance into a fully characterised one.
