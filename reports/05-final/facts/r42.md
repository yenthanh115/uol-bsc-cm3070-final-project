# R42 — All referenced work is properly cited

**Requirement (MUST):** All external work is cited consistently in ACM style, as explicitly required for full citation marks.

**Verdict: PASS**

This is a report-level requirement (References + in-text citations); no code is involved.

## In-text citation style — consistent and ACM-conformant

All in-text citations use ACM's numbered bracketed form `[N]` throughout the report, e.g. `[15]`, `[5]`, `[9]`, and grouped `[15][16][17]`, `[2][23]`, `[3][22]`. There is no mixing with author–date (Harvard) style. The highest in-text number used is `[23]`, and it resolves to a reference-list entry (verified).

## Reference list — complete and consistently formatted

The References section contains 23 entries numbered `[1]`–`[23]` with no gaps (verified). Every entry follows the same ACM pattern:

`[N] Author(s) (First Last, "and" before final). Year. Title. *Venue (italic)*, volume, issue (Month Year), page–range. DOI/URL`

Representative examples confirming format consistency across source types:

- Journal article: `[5] Gabor Szabo and Bernardo A. Huberman. 2010. Predicting the popularity of online content. *Commun. ACM* 53, 8 (August 2010), 80–88. https://doi.org/10.1145/1787234.1787254`
- Conference paper: `[9] Justin Cheng, Lada Adamic, P. Alex Dow, Jon M. Kleinberg, and Jure Leskovec. 2014. Can cascades be predicted? In *Proceedings of the 23rd International Conference on World Wide Web (WWW '14)*. ACM, New York, NY, USA, 925–936. https://doi.org/10.1145/2566486.2567997`
- Journal (abbrev. venue): `[22] Haibo He and Edwardo A. Garcia. 2009. Learning from imbalanced data. *IEEE Trans. Knowl. Data Eng.* 21, 9 (September 2009), 1263–1284. https://doi.org/10.1109/TKDE.2008.239`
- Web/report/dataset: `[1] FINRA. 2025. Social Media-Influenced Investing. ... Retrieved from https://...`; `[21] Leukipp. 2021. Reddit Finance Data. Kaggle. Retrieved from https://...`; `[14] Dogu Araci. 2019. FinBERT: ... Retrieved from https://arxiv.org/abs/1908.10063`
