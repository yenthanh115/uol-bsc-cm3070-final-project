# R40 — No stale experimental claims remain

**Requirement:** Old metrics, abandoned designs, obsolete figures and prototype-only statements have been removed or clearly identified as historical.
**Priority:** MUST
**Assessed:** 2026-09-05
**Verdict:** **PASS**

R40 has four hazards: (1) old metrics presented as current, (2) abandoned designs presented
as current, (3) obsolete/dangling figure references, and (4) prototype-only statements
presented as the finished system. Each was checked against the frozen run artefacts and the
figures directory; all four are either absent or explicitly framed as historical.

---

## 1. Old metrics — current figures are the latest; earlier values are labelled historical ✔

**Current headline numbers match the latest run artefacts.** The report's Results section
states XGB 0.892 / RF 0.880 on WSB and RF 0.753 on pennystocks. These match the most recent
(2026-07-19) final-summary artefacts:

- `output/evaluation/2026-07-19_08-28_final_summary.json`: `best_auc_roc = 0.8917` (XGB →
  report 0.892) and RF `auc_roc = 0.8801` (→ report 0.880) on WSB.
- `output/evaluation/2026-07-19_13-14_final_summary.json`: `best_auc_roc = 0.7527` (→ report
  0.753) on pennystocks.

So the numbers the report presents as current are the frozen final-run figures, not stale
ones.

**Earlier/superseded values are quarantined and explicitly narrated as history.** The only
pre-final metrics in the report sit in § "Implementation Decisions Driven by Empirical
Findings", each written as a resolved development episode:

- "**An early** timestamp conversion error … caused an unintended 89% record exclusion,
  leaving **only 7 positive** surge instances … Beyond **fixing** the unit bug …" — a fixed
  bug, not a current result.
- "**Initial experiments** on `r/pennystocks` (~80,000 records) produced as few as 7 positive
  test examples … **Scaling up** to `WSB` (577,872 records … 668 test surges) provided stable
  metric estimation." — the ~80,000/7 figures are explicitly the initial condition; the
  current figures (577,872 / 668) are the ones carried into `@tbl:dataset-characteristics`
  and the Results.
- "led XGBoost to achieve a high AUC of **0.888** … **identified as a probability calibration
  issue** … **successfully restored** probability alignment and recall." — 0.888 is a
  diagnostic waypoint; the final headline is 0.892.

Each earlier value carries a past-tense, superseded framing ("early", "initial", "fixing",
"restored"), satisfying R40's "clearly identified as historical".

## 2. Abandoned designs — captured as deliberately rejected, not as current ✔

Rejected alternatives are consolidated in `@tbl:design-alternatives` (SMOTE/synthetic
oversampling, network/diffusion features, LSTM/sequence models, post-hoc engagement features,
volume-only target, 6h/72h/multi-scale windows, closed ticker universe, multi-platform), each
with the reason for rejection and governing constraint. The volume-only target is explicitly
retained only "as a phase-1 control" (`@sec:sentiment-contribution`, `@tbl:phase-comparison`),
i.e. framed as a comparison baseline rather than the live design. No abandoned approach is
presented as part of the final system.

The prototype appears only as Phase 5 of the development plan (`@tbl:timeline`, "Feasibility
prototype") and as a de-risking step in the plan narrative. The Implementation Status section
states the opposite of a prototype-only claim: "All six pipeline stages … are fully
implemented and execute end-to-end on both datasets", with runtimes, determinism checks, and
30+ tracked runs. So no prototype-stage limitation is passed off as the final system's
capability.

## Verdict

**R40: PASS.** The report's current metrics (0.892 / 0.880 / 0.753) equal the latest
2026-07-19 frozen-run artefacts, and the only earlier numbers (7 positives, ~80,000 records,
AUC 0.888) are confined to the "Implementation Decisions Driven by Empirical Findings" section
and explicitly framed as historical development findings that were diagnosed and fixed.
Abandoned designs are recorded as deliberately rejected alternatives (`@tbl:design-alternatives`),
every one of the ten referenced figures exists on disk (no obsolete references), and the
prototype is described as a planned phase while the final system is stated to run end-to-end.
No stale experimental claim is presented as current.

### Minor observations (not blocking)

- Two figure files in `reports/05-final/figures/` are unreferenced by the report
  (`12_classification_threshold_sensitivity_xgboost.png`, the pennystocks surge-viability
  variant). These are surplus assets, not stale claims; removing them would tidy the folder
  but is not required by R40.
- The historical values in § "Implementation Decisions Driven by Empirical Findings" are
  correctly framed, but adding an explicit "(superseded)" tag would make the historical status
  even more unmistakable. Optional polish only.
