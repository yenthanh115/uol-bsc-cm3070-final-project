## Added ruff and mypy for static analysis (improvement 5)

### Context

The codebase uses type hints throughout but had no static analysis tooling configured. Adding linting and type checking catches type drift and style issues early, improving long-term maintainability.

### Changes

**Dependencies added** (`pyproject.toml` + `requirements.txt`):
- `ruff>=0.4` — fast Python linter and formatter
- `mypy>=1.10` — static type checker
- `pandas-stubs>=2.0` — type stubs for pandas

**Ruff configuration** (`[tool.ruff]` in `pyproject.toml`):
- Rule sets: E, W, F, I, UP, B, SIM, RUF (pycodestyle, pyflakes, isort, pyupgrade, bugbear, simplify, ruff-specific)
- Target: Python 3.10, line-length 100
- Suppressed: RUF001/2/3 globally (Unicode math notation σ, μ, × is intentional in a research project)
- Per-file ignores for test directory (E712 boolean comparisons, F841 unused vars)
- isort configured with `surge_pipeline` as first-party

**Mypy configuration** (`[tool.mypy]` in `pyproject.toml`):
- `check_untyped_defs = true` — type-check function bodies even without annotations
- `ignore_missing_imports = true` — don't fail on untyped third-party libs
- Per-module overrides for pandas/numpy stub false positives (operator, index, union-attr, assignment, arg-type, return-value suppressed in modules that heavily use `.values` patterns)

### Issues fixed during initial run

Ruff found 252 issues; 182 auto-fixed, remaining fixed manually:
- **Import sorting** (I001) — all imports reorganised to isort standard
- **Deprecated typing imports** (UP006/UP035) — `List` → `list`, `Dict` → `dict`, `Optional[X]` → `X | None`
- **Unused imports** (F401) — removed `io`, `Tuple`, stale late imports
- **Undefined name** (F821) — added missing `PipelineConfig` import to `evaluation.py`
- **Unused loop variables** (B007) — `for ticker, group` → `for _ticker, group` in windowing/features/sentiment
- **Unused assignment** (F841) — removed dead `n = len(df)` in labelling.py
- **Matplotlib type fix** — `set_xlim([...])` → `set_xlim((...))` (tuple, not list)
- **Stale type:ignore comments** — removed from `cli_logging.py`
