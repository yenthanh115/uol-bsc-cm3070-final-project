## Design Rationale: Why VADER over TextBlob and FinBERT

### VADER vs TextBlob

TextBlob uses a pattern-based approach trained on movie reviews. It does not understand:
- Capitalisation as emphasis ("THIS IS HUGE" scores same as "this is huge")
- Exclamation marks as intensifiers ("great!!!" = "great")
- Slang and informal language common on Reddit
- Emoticons or punctuation-heavy expressions

VADER was specifically designed for social media text with hand-crafted rules for:
- Capitalisation boosting (+15% intensity)
- Exclamation mark intensification
- Degree modifiers ("extremely", "kind of")
- Negation handling ("not great")
- Slang/acronyms common in online communities

Example: "$GME YOLO!! diamond hands!! 🚀🚀🚀" → VADER: +0.75, TextBlob: ~0.0

### VADER vs FinBERT

FinBERT (ProsusAI/finbert) is a transformer fine-tuned on financial news. It would likely produce better signals for formal financial text, but is wrong for this project because:

1. **Runtime**: FinBERT on ~50k records takes 30–60 min on CPU. VADER runs in seconds. Pipeline re-runs become impractical.
2. **Dependency weight**: Requires `transformers` + `torch` (~2GB). Current project has lightweight deps only.
3. **Reproducibility risk**: HuggingFace model weights can change between versions. VADER's lexicon is deterministic and bundled locally.
4. **Domain mismatch**: FinBERT trained on formal financial news ("Q3 earnings beat expectations"), not Reddit slang ("AAPL gonna moon fr fr"). Domain gap may negate its advantage.
5. **Scope**: For a BSc project, VADER is a defensible, widely-cited choice. FinBERT is valid "future work".

### Comparison Table

| Criterion | TextBlob | VADER | FinBERT |
|---|---|---|---|
| Social media text | Poor | Good | Moderate |
| Financial domain | Poor | Moderate | Good |
| Runtime (50k records) | ~5s | ~3s | ~45min (CPU) |
| Dependencies | Light | Light | Heavy (2GB+) |
| Reproducibility | Deterministic | Deterministic | Model-version dependent |
| Academic justification | Weak | Strong (widely cited) | Strong but overkill |

### Conclusion

VADER gives the best signal improvement for the least cost. FinBERT is acknowledged as a limitation and future work item in the report.
